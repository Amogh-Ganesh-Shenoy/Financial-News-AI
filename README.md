# Financial News AI 📈🏦

An end-to-end AI-powered financial intelligence platform built with 
Python, OpenAI GPT, LangChain, and Streamlit.

## Project Structure

### Phase 1 — Financial News Sentiment Analysis
Fetches live financial news and analyses each article using AI.
Returns a summary, market sentiment (Bullish/Bearish/Neutral), 
key companies mentioned, and investor insight.

**Built with:** Python · OpenAI GPT-3.5-turbo · NewsAPI · pandas

---

### Phase 2 — Financial PDF RAG Chatbot
Upload any financial PDF report and chat with it using 
Retrieval Augmented Generation (RAG). Answers are grounded 
in the document — no hallucination.

**Built with:** Python · LangChain · FAISS · OpenAI · PyPDF

---

### Phase 3 — JPMorgan Financial Intelligence App
A full deployed financial intelligence dashboard focused on 
JPMorgan Chase. Combines live market data, RAG-powered chat 
over financial data, and advanced analytics — all in one 
professional web application.

**Built with:** Python · Streamlit · OpenAI · LangChain · 
yfinance · FAISS · Plotly

---

## Tech Stack
| Technology | Purpose |
|---|---|
| Python 3.11 | Core language |
